# Explore the Universe

Space Buddy should feel like an intelligent planetarium that can open into a much larger universe.

## Live sky view

The starting view is an accurate sky for a user selected or consented location, date and time. Stars, planets, constellations and supported objects should appear where trusted astronomical data says they should be.

Location should be optional and privacy controlled. Users should also be able to enter a city or select a place manually.

## Adaptive planetary viewpoints

The observer should not be limited to Earth. A user could stand on the Moon and look toward Earth, move to Mars and inspect the sky there, or compare how the same object appears from different parts of the Solar System where the underlying models support it.

## Free roam navigation

Users can leave the local sky and travel anywhere the product supports. Navigation should have clear speed controls so inspection can happen at human scale while long distance travel can accelerate through planetary, stellar and cosmic scales.

The AI companion can act as a transport layer:

“Take me to Europa.”

“Now show me Jupiter from Europa.”

“Take me to the center of the Milky Way.”

## Progressive object interaction

The interface uses three levels of engagement.

**Hover:** optional minimal information for orientation.

**Single click:** a detailed panel with measurements, source links, related missions, observations and actions.

**Double click or explicit Ask Space Buddy action:** opens conversation about the object and can begin spoken explanation with synchronized captions.

## Object rotation

For supported 3D models, the object itself can rotate on its axis. A dedicated control helps users inspect a model without forcing all interaction into camera orbit behavior.

## Visual direction

The universe remains the primary interface. Deep black space, white stars, restrained neutral controls and translucent panels create a modern observatory feel.

Users should be able to hide chat, captions and panels completely when they want uninterrupted exploration.

Desktop prioritizes the large visual canvas. Mobile should favor landscape exploration when practical and keep text inside translucent panels that preserve the view behind it.
